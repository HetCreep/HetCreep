# Hi, I'm HetCreep ⛏️

I build **safety-first tooling for AI agents** from Thailand — tools that measure instead of trust, ask before they spend, and verify or flag instead of guessing.

## ⚒️ The Colliery

A mining series of quality/safety tools for AI coding agents — mostly cross-agent (Claude Code, Antigravity, Codex, Cursor and more); each tool's README states exactly how far it has been taken, and CoalTipple is Claude Code only. The State column tells the two kinds apart: a *stable* tool has a published stable Release, a *beta* tool has none yet.

New here? [CoalMine](https://github.com/TheColliery/CoalMine) is the most fully-shipped tool and the natural starting point.

| Tool | What it does | State |
|---|---|---|
| [CoalMine](https://github.com/TheColliery/CoalMine) | 9 quality canaries — code rot, security, drift, supply-chain — wired to fire automatically at session end | stable |
| [CoalTipple](https://github.com/TheColliery/CoalTipple) | Model/effort router — delegates cheap work down, escalates hard work up | stable |
| [CoalBoard](https://github.com/TheColliery/CoalBoard) | Multi-lens consensus board for error-not-allowed decisions | stable |
| [CoalHearth](https://github.com/TheColliery/CoalHearth) | Session warm-resume + handoff journal | stable |
| [CoalFace](https://github.com/TheColliery/CoalFace) | Fan-out discipline for multi-agent swarms — bounded cost, single-writer apply | stable |
| [CoalWash](https://github.com/TheColliery/CoalWash) | Memory washer/defragmenter with a mechanical fidelity gate | stable |
| [CoalLedger](https://github.com/TheColliery/CoalLedger) | Docs-health canaries — "CoalMine for documentation" | beta |
| [CoalGob](https://github.com/TheColliery/CoalGob) | Recoverable-delete guard for AI coding agents. Classifier only: no hook yet, so nothing is blocked or rerouted today | beta |

📖 **Docs:** [TheColliery documentation](https://thecolliery.org/docs)

**License:** every tool above is Apache-2.0.

**House rules the whole series lives by:** zero dependencies · offline-capable · fail-silent hooks that never break your session · every costly action consent-gated · honest claims only (a README must match what the code actually does).
