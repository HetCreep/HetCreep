# Hi, I'm HetCreep ⛏️

I build **safety-first tooling for AI agents** from Thailand — tools that measure instead of trust, ask before they spend, and verify or flag instead of guessing.

## ⚒️ The Colliery

A mining series of quality/safety tools for AI coding agents — cross-agent by design (Claude Code, Antigravity, Codex, Cursor, and any SKILL.md-compatible tool):

| Tool | What it does |
|---|---|
| [CoalMine](https://github.com/HetCreep/CoalMine) | 9 quality canaries — code rot, security, drift, supply-chain — wired to fire automatically at session end |
| [CoalTipple](https://github.com/TheColliery/CoalTipple) | Model/effort router — delegates cheap work down, escalates hard work up |
| [CoalBoard](https://github.com/TheColliery/CoalBoard) | Multi-lens consensus board for error-not-allowed decisions |
| [CoalHearth](https://github.com/TheColliery/CoalHearth) | Session warm-resume + crash-safe handover journal |
| [CoalFace](https://github.com/TheColliery/CoalFace) | Fan-out discipline for multi-agent swarms — bounded cost, single-writer apply |
| [CoalWash](https://github.com/TheColliery/CoalWash) | Memory washer/defragmenter with a mechanical fidelity gate |
| [CoalLedger](https://github.com/TheColliery/CoalLedger) | Docs-health canaries — "CoalMine for documentation" |

**House rules the whole series lives by:** zero dependencies · offline-capable · fail-silent hooks that never break your session · every costly action consent-gated · honest claims only (a README must match what the code actually does).
